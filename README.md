# Трекер привычек

Техническое задание (Software Requirements Specification) для приложения
**«Трекер привычек»** — ежедневное отслеживание полезных привычек
(спорт, вода, чтение) с графиком прогресса.

## Состав репозитория

- **Wiki → «Техническое задание»** — основной документ ТЗ.
- **Issues** — детализированные требования (User Stories + критерии приёмки),
  связанные с разделами ТЗ.
